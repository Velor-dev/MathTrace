Do not introduce phases, rename commands, reorder work, dispatch every role, or interpret these adapters as an automatic pipeline. `mathtrace-help` only displays the reference guide.

Read the selected harness's `README.md`, this file and the relevant shared skill. The shared `PROTOCOL.md` preserves the existing mathematical contract. Its **Antigravity-specific transport** (`invoke_subagent`, reservation, producer inspection/admission/capture/recovery) applies only to Antigravity with the existing owned runtime. On other hosts, use only that harness's documented delegation binding for exploratory proposals. Do not translate Antigravity capture calls into another tool name, invent producer UUIDs/receipts, or present another host's transcript as qualified native evidence. These packages contain no new runtime capture backend. Manual imports cannot qualify independent reviews; audit, release and fulfillment gates remain unchanged and may be blocked.

The eight shared skills and eleven role bodies are the single maintained workflow/prompt source for the ports. The original protocol is a snapshot, with this transport scope clarification. Role bodies are embedded in native custom-agent files where supported so a tool-free worker need not read them. For dynamic delegation the root reads the exact selected role body and supplies it verbatim with the complete exact task packet. Do not give a blind worker the root conversation, project/build history, other verdicts, all skills, this root policy, or state-reading instructions. Supply only the role, exact packet and necessary task-neutral host instructions. Workers return the existing JSON result contract; root alone assesses results, executes computation and commits canonical state. Worker availability is never authorization for a tool call.

The user chooses the root model and reasoning effort. Leave child model/effort unset, or use a documented literal `inherit`; MathTrace adds no router, aliases selecting another model, or effort override. A different child configuration is a manual user choice. The user's Antigravity inheritance observation remains resolved. Other hosts' defaults/global configuration can still affect effective execution; these unlaunched wrappers do not certify them. If a host cannot preserve the selected settings, disclose the mismatch rather than silently choosing alternatives.

Tool-free is the assigned worker policy. Apply documented native restrictions where available, but do not equate a configuration file, fresh context, read-only mode or a separate worktree with proven tool/context isolation. Inspect actual task-specific leakage and effective tool/state access. Benign platform-guide skills alone are not contamination. Report unexpected tools/context. Inline critique is not an independent audit and cannot clear a gate requiring independence. Do not invent native agent files or install extensions to conceal this limitation.

Keep local host memory and advice separate from canonical campaign evidence.
