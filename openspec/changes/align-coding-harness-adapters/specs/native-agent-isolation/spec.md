## ADDED Requirements

### Requirement: Deterministic Portable Specialist Payloads
The system SHALL generate portable harness payloads deterministically from the shared eleven roles and eight workflows, preserving mathematical role bodies and JSON contracts exactly. Payload generation SHALL NOT install hosts, select provider models or certify independent mathematical admission.

#### Scenario: Native profile generation
- **WHEN** Cline or current Kimi Code payloads are generated
- **THEN** eleven native profiles embed the unchanged shared role bodies with empty tool lists and eight workflow wrappers are generated in the documented native skills directory
- **AND** Cline uses the audited `.cline/agents/*.yaml` frontmatter-plus-body contract, while Kimi Code uses `.kimi-code/agents/*.md` with an empty subagent allowlist

#### Scenario: Repeated and selected generation
- **WHEN** the same inputs are rendered repeatedly or a single harness is selected
- **THEN** generated bytes remain deterministic and unselected harness payloads and the preserved Antigravity agent snapshot remain unchanged

### Requirement: Explicit Harness Version Compatibility
The system SHALL separate incompatible OpenCode permission dialects into explicitly selected staging payloads, preserve Kilo's supported dialect, and document effective tool and model-effort limitations without replacing missing qualification with configuration claims.

#### Scenario: OpenCode version selection
- **WHEN** an operator chooses OpenCode V1 or V2
- **THEN** the operator receives respectively singular wildcard permission denial or plural ordered action-resource-effect denial rules
- **AND** deployment instructions prohibit merging both same-name role sets into one active discovery directory

#### Scenario: Unsupported inheritance or tool enforcement
- **WHEN** a host's effective model, effort, context or tools cannot satisfy required worker constraints
- **THEN** documentation retains the incompatibility and independent-admission limits without automatic model routing, tool grants or modified mathematical bodies
